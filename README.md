# Piano Circuit PCB Design

## Description
Designed a piano circuit PCB using EAGLE, converting a schematic into a fully routed PCB layout ready for fabrication.

## Features
- Multi-key input circuit design
- Compact PCB layout with optimized routing
- Proper component placement and trace design
- Gerber file generation for manufacturing

## Tools Used
- Autodesk EAGLE

## Files Included
- Schematic design
- PCB layout

## Working
The circuit generates different tones based on key inputs, simulating a basic electronic piano functionality.

## Outcome
Developed practical experience in PCB design workflow from schematic creation to fabrication-ready output.
